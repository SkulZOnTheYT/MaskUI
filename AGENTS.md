# MaskUI project preferences

- Keep the plugin version at 1.0.0. Do not bump it for routine changes unless the user explicitly asks.
- Whenever mask effects change, update wiki.md to match MaskType.java.
- Prefer right-click armor-style equipping over equip/unequip commands.
- Keep work and responses concise. Do not run tests unless the user asks; the user tests in game. Build the JAR with tests skipped.
- Target Minecraft 1.16.x–1.21.x using the 1.16.1 API and Java 8-compatible production code. Use fallbacks for newer materials/APIs.
